{{- /* Returns one llms.txt list line for a regular page: - [Title](https://host/path.md): summary - Published 2026-01-02 Input: dict "page" (Page) "prodHost" (string). Link target: the page's `.md` URL when the site publishes the `markdown` output format for it, otherwise its HTML URL. The old templates appended `.md` unconditionally, which 404s on a site that turns markdown off. Summary: the front matter `description` first, because it is written to stand alone. Only when it is missing does this fall back to Hugo's auto-summary, and then it cuts the HTML at the first callout. Without that cut, a page that opens with a NOTE callout leaked the callout's title into llms.txt as a stray "Note" line followed by the callout body. `htmlUnescape` turns `’`-style entities that `plainify` leaves behind back into characters, and the whitespace collapse keeps every entry on one line. Summaries over 160 characters are cut, up from the old 100, so most front matter descriptions survive whole. */ -}} {{- $p := .page -}} {{- $prodHost := .prodHost -}} {{- $url := print $prodHost $p.RelPermalink -}} {{- if $p.OutputFormats.Get "markdown" -}} {{- $url = print $prodHost ($p.RelPermalink | strings.TrimSuffix "/") ".md" -}} {{- end -}} {{- $summary := $p.Description -}} {{- if not $summary -}} {{- $html := string $p.Summary -}} {{- $html = replaceRE `(?s)]*data-alert-type.*$` "" $html -}} {{- $summary = $html | plainify -}} {{- end -}} {{- $summary = $summary | htmlUnescape | replaceRE `\s+` " " | strings.TrimSpace -}} {{- if gt (len $summary) 160 -}} {{- /* `truncate` HTML-escapes a plain string (Istio's -> Istio's), so unescape again after it. */ -}} {{- $summary = truncate 160 $summary | htmlUnescape -}} {{- end -}} {{- $line := printf "- [%s](%s)" $p.Title $url -}} {{- with $summary -}}{{- $line = printf "%s: %s" $line . -}}{{- end -}} {{- if not $p.Date.IsZero -}} {{- $line = printf "%s - Published %s" $line ($p.Date.Format "2006-01-02") -}} {{- end -}} {{- return $line -}}
