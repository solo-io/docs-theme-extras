{{- /* first-leaf.html — return the RelPermalink of the first leaf page under a node. Used by the docs-tabs band so clicking a tab lands on the tab's first actual page, not a section landing/index page (issue solo-io/docs#3164). Input: a Page. If it is a section with children, recurse into its first child (Hugo orders .Pages by weight then title); otherwise return the page's own RelPermalink. Depth is bounded by the content tree, which is shallow. */ -}} {{- $p := . -}} {{- if and $p.IsSection (gt (len $p.Pages) 0) -}} {{- partial "utils/first-leaf.html" (index $p.Pages 0) -}} {{- else -}} {{- $p.RelPermalink -}} {{- end -}}
