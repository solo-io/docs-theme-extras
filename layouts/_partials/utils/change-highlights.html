{{- /* Change-highlights overlay: non-production builds only. Emits the list of source files that produced this page (the page's own file plus every snippet the `reuse` shortcode pulled in, recorded in .Store "extrasChangeSources") and loads assets/js/change-highlights.js, which fetches the manifest written by scripts/changes_manifest.py and highlights the added text. The manifest is NOT read here. Keeping it out of the templates means a rewrite of the manifest never triggers a page re-render under `hugo server`. Called from head.html after its `.WordCount` call, which forces .Content to render first, so the Store already holds every reuse made on the page. On outside production by default.
