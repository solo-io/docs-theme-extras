{{- /* Shortcode: github Summary: Fetches a remote file by URL and inlines its contents Group: external-content CallForm: both Overrides: none Parameters: - url | url | yes | — | The remote URL of the file to fetch and display. Example: code-only Notes: Behavior depends on the URL's file extension. A `.md` URL is rendered through the page's Markdown renderer, so headings, tables and links inside the fetched file render correctly. Anything else — YAML, JSON, plain text — is passed through with `safeHTML`, and callers typically wrap the call in a code fence so it renders as a code block. For a YAML file specifically, prefer `github-yaml`: it writes the fence for you, strips the editor schema directive, captions the block and uses a date-stamped cache key. ### Network behavior `timeout` caps a slow or unreachable remote so a cold CI build with no getresource cache fails fast instead of hanging, and `try` (required since Hugo v0.141 removed `resource.Err`) turns a transient fetch error into a warning plus a link-checker-visible fallback rather than a crash. A dead or 404 URL is different: it produces a nil resource with no error, which is treated as a real reference bug and fails the build with `errorf`. The distinction is deliberate — a flaky network should not break a build, and a wrong URL should. The example is marked `code-only`: a live render would hit the network on every site build. */ -}} {{- $url := .Get "url" -}} {{- $attempt := try (resources.GetRemote $url (dict "timeout" "15s")) -}} {{- with $attempt.Err -}} {{- warnf "github: failed to fetch %q: %s" $url . -}}

Error: Unable to load code from {{ $url }}

{{- else -}} {{- with $attempt.Value -}} {{- if hasSuffix $url ".md" -}} {{- $.Page.RenderString .Content -}} {{- else -}} {{- .Content | safeHTML -}} {{- end -}} {{- else -}} {{- /* A nil .Value with no .Err means the host responded but the resource is absent (a 404 / dead or moved URL) — a real reference bug in the docs, not a transient network blip — so fail the build LOUDLY, mirroring github-table's missing-section errorf. Contrast the .Err branch above, which stays a WARN because a timeout/transport error can be transient on a cold CI build. */ -}} {{- errorf "github: no content at %q (dead or moved URL) — fix or remove the reference" $url -}} {{- end -}} {{- end -}}
