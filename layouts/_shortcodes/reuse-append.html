{{- /* Shortcode: reuse-append Reads a base markdown snippet from the assets tree, appends the inner content to it, and renders the combined result through the page's markdown renderer. Parameters: - 0 (positional, required): path to the base file in the assets tree. - 1 (positional, optional): version, passed down from a parent shortcode. ASSET RESOLUTION HANDLES BOTH TREE SHAPES, and it has to. An OSS site's assets tree is FLAT (`agw-docs/snippets/x.md`), while the docs hub ASSEMBLES its tree per version at `assets///…`. So the versioned path is tried first and the bare path second: 1. `//` — the hub's assembled shape. Skipped entirely when either value is empty, which is the case on every flat site. 2. `` — the bare path, correct for a flat tree and for a hub product that is not assembled. Only if BOTH miss is it an error. A single bare `resources.Get` — which is what this file did when it was first adopted from agentgateway-oss-website — resolves fine on the OSS site and misses on every assembled hub page, so the `errorf` below fired on content that was previously building. The hub had been carrying its own adapted copy of this shortcode for exactly this reason; folding the resolution in here is what lets that copy be deleted. The version is resolved the way `reuse.html` does when no parent passes one: scan the page's permalink for a segment matching a `[[params.versions]]` entry. TODO: that is a thirteenth independent URL parser in this module, and the duplicated ones have historically drifted (see `utils/version-root.html`, which `resolve-link.html` was moved onto for this reason). Consolidating this onto `version-root.html` needs a docs-hub build to verify against the assembled assets tree, so it is deliberately left alone here rather than changed blind. Example: {{< reuse-append "snippets/provider-base-configuration.md" >}} | Extra row | Value | {{< /reuse-append >}} WHAT IT IS FOR. A snippet that is a markdown TABLE cannot be extended by calling `reuse` and then writing more rows after it: `reuse` renders the snippet on its own, so the table is already closed as `` HTML by the time the extra rows are parsed, and they render as a stray paragraph of pipes instead of joining the table. Concatenating the two as SOURCE and rendering once keeps them a single markdown block. The same reasoning applies to any construct whose continuation depends on the preceding lines — lists, definition blocks, a fenced code block split across the boundary. IT IS NOT A VARIANT OF `reuse`. Despite the name, this shortcode does NOT apply the version- and product-aware shortcode rewrites that `reuse` does; it is a plain `resources.Get` plus concatenation. A base snippet containing a `version` shortcode, `keepVersion` blocks, or `link-hextra` calls that rely on rebase-injected params will therefore behave differently here than under `reuse`. Keep base snippets used with this shortcode free of version-dependent markup, or use `reuse` and restructure the content so appending is not needed. Errors, not warnings, on a missing positional parameter or a missing asset: both mean the call site names a file that is not there, which is a content bug that silently renders nothing if it is allowed to pass. */ -}} {{- $asset := "" -}} {{- with (.Get 0) -}} {{- $asset = . -}} {{- else -}} {{- errorf "The %q shortcode requires one positional parameter: path in /assets. See %s" .Name .Position -}} {{- end -}} {{- $asset = strings.TrimPrefix "/" $asset -}} {{- /* A parent shortcode may pass the version down as positional 1. */ -}} {{- $parentVersion := "" -}} {{- if ge (len .Params) 2 -}}{{- $parentVersion = .Get 1 -}}{{- end -}} {{- $resolvedVersion := $parentVersion -}} {{- if not $resolvedVersion -}} {{- range $urlPart := split .Page.RelPermalink "/" -}} {{- if not $resolvedVersion -}} {{- range $.Site.Params.versions -}} {{- if eq .version $urlPart -}}{{- $resolvedVersion = .version -}}{{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- /* Assembled-tree path first, bare path second. See the header comment. */ -}} {{- $res := "" -}} {{- $currentProduct := .Site.Params.currentProduct | default "" -}} {{- if and $resolvedVersion $currentProduct -}} {{- $res = resources.Get (printf "%s/%s/%s" $currentProduct $resolvedVersion $asset) -}} {{- end -}} {{- if not $res -}} {{- $res = resources.Get $asset -}} {{- end -}} {{- if not $res -}} {{- errorf "The %q shortcode could not find %q (tried the assembled path %q/%q/ first). See %s" .Name $asset $currentProduct $resolvedVersion .Position -}} {{- end -}} {{- $base := trim $res.Content " \n\r\t" -}} {{- $extra := trim .Inner " \n\r\t" -}} {{- $combined := printf "%s\n%s\n" $base $extra -}} {{- $combined | .Page.RenderString -}}
