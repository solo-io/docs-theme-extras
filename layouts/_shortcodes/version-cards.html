{{- /* Shortcode: version-cards Renders a .section-cards grid mirroring the navbar version dropdown. Designed for a section landing page; each card links to //. Resolves versions through utils/resolve-section-versions.html — the single place that knows which entries in site.Params.versions apply to a section (each entry names its sections; an untagged entry applies to all). This used to read site.Params.sections.
.versions itself, with a fallback to the top-level list, which meant the priority rule lived here AND in the sidebar AND in the navbar AND in version-root.html, and they drifted. Each version item is expected to expose `dropdown` (label) and `linkVersion` (URL slug). Items whose `dropdown` is empty/whitespace are skipped, matching navbar.html's visibility rule. Parameters: - section: (optional) Key under site.Params.sections. Defaults to the last segment of the current page's URL — e.g. on /docs/kubernetes/ the section is "kubernetes". - desc: (optional) Description rendered under each card title. Supports Markdown. Sets .Page.Store "hasManualCards" so the auto-section-cards partial in docs/list.html does not also emit child-section cards. Example: {{< version-cards desc="Use product X in a Kubernetes environment." >}} */ -}} {{- $section := .Get "section" -}} {{- if not $section -}} {{- $segs := split (strings.Trim .Page.RelPermalink "/") "/" -}} {{- if gt (len $segs) 0 -}} {{- $section = index $segs (sub (len $segs) 1) -}} {{- end -}} {{- end -}} {{- $desc := .Get "desc" -}} {{- $versions := partial "utils/resolve-section-versions.html" $section -}} {{- $base := strings.TrimRight "/" .Page.RelPermalink -}} {{- if gt (len $versions) 0 -}} {{- $.Page.Store.Set "hasManualCards" true -}}
{{- range $versions -}} {{- $label := .dropdown | default .version -}} {{- if and $label (ne (strings.Trim $label " ") "") -}} {{- /* `//`, so dev and preview baseURLs stay relative. Every entry in site.Params.versions is THIS product's, so there is nothing to branch on: other products' versions live in site.Params.relatedDocs (CHANGELOG [1.0.0]). This used to carry a cross-product branch that took an entry's explicit `url`. It never ran anywhere: this shortcode is used only by agentgateway's kubernetes section, agentgateway-oss-website, kgateway-oss and this fixture, and none of them has (or had) a cross-product entry — the two OSS sites set no `currentProduct` at all, which made every entry same-product by definition. Related products are deliberately NOT rendered as cards. This grid sits on a section landing page and answers "which version of THIS product, in this section" — a card pointing at another product's site would be a different question. The version dropdown is where cross-product navigation belongs. */ -}} {{- $href := printf "%s/%s/" $base .linkVersion -}} {{ $label }} {{- if $desc }}{{ $desc | markdownify }}{{ end -}} {{- end -}} {{- end -}}
{{- else -}} {{- warnf "version-cards: no versions apply to section %q on %s. Check that site.Params.versions has entries whose `sections` list includes it (or that omit `sections`, meaning every section)." $section .Page.RelPermalink -}} {{- end -}}
