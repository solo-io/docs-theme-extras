{{- /* Initialize */ -}} {{- $asset := "" -}} {{- $parentVersion := "" -}} {{- $parentProduct := "" -}} {{- /* Get params */ -}} {{- with (.Get 0) -}} {{- $asset = . -}} {{- else -}} {{- errorf "The %q shortcode requires a single positional parameter; the relative path to a file in the assets directory. See %s" .Name .Position -}} {{- end -}} {{- /* Optional second param: version passed from parent */ -}} {{- if ge (len .Params) 2 -}} {{- $parentVersion = .Get 1 -}} {{- end -}} {{- /* Optional third param: product passed from parent */ -}} {{- if ge (len .Params) 3 -}} {{- $parentProduct = .Get 2 -}} {{- end -}} {{- /* Strip leading slash from asset paths */ -}} {{- $asset = strings.TrimPrefix "/" $asset -}} {{- /* For assembled products, try the versioned path at // first. Falls back to the direct path for non-assembled products that also have versions (e.g. gloo-mesh). In the OSS repo (no currentProduct/versions), the path is used as-is. */ -}} {{- $resolvedVersion := $parentVersion -}} {{- if not $resolvedVersion -}} {{- $urlParts := split .Page.RelPermalink "/" -}} {{- range $urlPart := $urlParts -}} {{- if not $resolvedVersion -}} {{- range $.Site.Params.versions -}} {{- if eq .version $urlPart -}} {{- $resolvedVersion = .version -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- $currentProduct := .Site.Params.currentProduct | default "" -}} {{- if and $resolvedVersion $currentProduct -}} {{- $versionedAsset := printf "%s/%s/%s" $currentProduct $resolvedVersion $asset -}} {{- $versionedR := resources.Get $versionedAsset -}} {{- if $versionedR -}} {{- $asset = $versionedAsset -}} {{- end -}} {{- end -}} {{- /* Get resource */ -}} {{- $r := resources.Get $asset -}} {{- if not $r -}} {{- errorf "The %q shortcode was unable to find %q. See %s" .Name $asset .Position -}} {{- end -}} {{- $content := $r.Content -}} {{- /* Strip front matter */ -}} {{- $content = replaceRE `(?s)^---.*?---\s*` "" $content -}} {{- /* Inject parent version into nested link/reuse shortcodes */ -}} {{- if $parentVersion -}} {{- /* Add version to link shortcodes */ -}} {{- $content = replaceRE `{{<\s*link-hextra\s*(.*?)>}}` (printf "{{< link-hextra $1 version=\"%s\" product=\"%s\" >}}" $parentVersion $parentProduct ) $content -}} {{- $content = replaceRE `{{<\s*reuse\s*"([^"]+)"\s*>}}` (printf "{{< reuse \"%s\" \"%s\" \"%s\" >}}" "$1" $parentVersion $parentProduct ) $content -}} {{- /* keepVersion: preserve version string, inject parent version, convert to {{% %}} */ -}} {{- $content = replaceRE `\{\{<\s*(version\s+(?:include|exclude)-if="[^"]+?")\s+keepVersion="true"\s*>}}` (printf `{{%% $1 version="%s" %%}}` $parentVersion) $content -}} {{- /* Protect keepVersion blocks from the OSS→enterprise remap below. keepVersion="true" means the author wrote the ENTERPRISE version tokens directly (e.g. kgw-docs/versions/github-branch.md maps include-if="2.3.x" → main), so the tokens must NOT be remapped as if they were OSS versions. The keepVersion transform above tags these blocks with the injected version="..." param, which distinguishes them from genuine percent-form blocks (the get_cookie rows) that carry no version= param and DO need remapping. Rename the condition attribute to a remap-invisible token (no "clude-if" substring, so the remap regex below can't match it), then restore it after the remap. rebase.html avoids this because its remap regex is angle-only and keepVersion blocks are percent-form; reuse.html matches both forms, so it needs this guard. Symptom without it: kgw enterprise sample-app httpbin URLs rendered a shifted/empty/doubled branch. */ -}} {{- $content = replaceRE `(\{\{%\s*version\s+)include-if=("[^"]*"\s+version=")` "${1}kvincif=${2}" $content -}} {{- $content = replaceRE `(\{\{%\s*version\s+)exclude-if=("[^"]*"\s+version=")` "${1}kvexcif=${2}" $content -}} {{- /* Two-pass OSS→enterprise version remapping from [[params.versions]]. Pass 1 replaces OSS versions with indexed placeholders so overlapping version strings (e.g. OSS 2.2.x vs enterprise 2.2.x) never double-match. Pass 2 swaps placeholders for the enterprise versions. */ -}} {{- range $i, $v := $.Site.Params.versions -}} {{- if and $v.ossVersion (ne $v.ossVersion $v.version) -}} {{- $oss := replaceRE `\.` `\.` $v.ossVersion -}} {{- $ph := printf "__V%d__" $i -}} {{- /* Match BOTH angle ({{< >}}) and percent ({{% %}}) version blocks. Unlike rebase.html, reuse.html does not bulk-convert percent→angle before remapping, so an OSS version number authored in a percent- form block (e.g. the get_cookie table rows in templating-language.md, `{{% version include-if="2.4.x,2.5.x" %}}`) would otherwise never be remapped to the enterprise version and the gated rows would be excluded on the enterprise build. */ -}} {{- $content = replaceRE (printf `(\{\{[<%%]\s*version\s[^>%%]*?(?:in|ex)clude-if="[^"]*?)%s` $oss) (printf "${1}%s" $ph) $content -}} {{- end -}} {{- end -}} {{- range $i, $v := $.Site.Params.versions -}} {{- if and $v.ossVersion (ne $v.ossVersion $v.version) -}} {{- $ph := printf "__V%d__" $i -}} {{- $content = replace $content $ph $v.version -}} {{- end -}} {{- end -}} {{- /* Restore the keepVersion condition attributes protected above. */ -}} {{- $content = replace $content "kvincif=" "include-if=" -}} {{- $content = replace $content "kvexcif=" "exclude-if=" -}} {{- /* Leave remaining {{< version >}} blocks in angle-bracket form so .Inner stays as raw markdown for version.html. The percent form ({{% %}}) would trigger Hugo's parent-context pre-render of .Inner BEFORE version.html runs, and indented inner content would get wrapped in

{{- /* Table-row exception: a {{< version >}} that wraps one or more
       pipe-delimited rows needs the percent form so the shortcode output
       re-enters the markdown stream and the pipes get parsed as cell
       delimiters. Angle form would emit opaque HTML inline and Goldmark
       would treat the whole pipe-string as one  (or drop a multi-row
       block entirely, since the rows land in the placeholder after the
       table is parsed). The content group `(?:\s*\|[^\n]*\|)+` matches a
       single same-line row OR several rows across lines (inter-row `\n`
       absorbed by the leading `\s*`); every matched line must be a full
       `|...|` row, so it won't affect the indented-list or fence-adjacent
       cases that rely on staying in angle form. Mirrors rebase.html. */ -}}
{{- $content = replaceRE `\{\{<\s*(version\s+(?:include|exclude)-if="[^"]+"[^>]*?)\s*>}}((?:\s*\|[^\n]*\|)+\s*)\{\{<\s*/version\s*>}}` "{{% $1 %}}$2{{% /version %}}" $content -}}

{{- /* List-item exception: a version block whose inner content starts
       with a bullet or numbered list marker at column 0 needs the percent
       form so the marker re-enters the markdown stream as a real list
       item. Angle form would emit the marker as literal text in the
       surrounding placeholder context — when the version wraps a single
       bullet adjacent to other bullets, Goldmark lazy-continues the prior
       `
  • ` and the `* [link](url)` survives as raw markdown (the leak
       shape in `policy-merging.md`'s "Merging examples" list). Matches
       same-line wraps (`{{< version >}}* item{{< /version >}}`) and
       newline-prefixed multi-item blocks. Content must start at column 0
       (no leading spaces before the marker) so we don't trip deeply-
       indented version blocks where percent form's 4-space-code-block
       rule would wrap inner content in `
    `. Mirrors the same
       conversion in rebase.html. */ -}}
{{- $content = replaceRE `\{\{<\s*(version\s+(?:include|exclude)-if="[^"]+"[^>]*?)\s*>}}((?:\r?\n)?(?:[*+\-]|[0-9]+\.)[ \t][\s\S]*?)\{\{<\s*/version\s*>}}` "{{% $1 %}}$2{{% /version %}}" $content -}}

{{- /* Prefix root-absolute  with the site's baseURL path so
       OSS-authored static image refs (e.g. /integrations/providers/*.svg, which
       assume an OSS site served at root) resolve when the hub serves this
       product under a path prefix (e.g. /agentgateway/). relURL only prefixes
       RELATIVE inputs, so the prefix is computed once and spliced into the
       root-absolute src; on a root-served site (OSS, local) the prefix is "/"
       and this is a no-op. Scoped to  — relative, external
       (https://), and href values are left untouched. Mirrors rebase.html. */ -}}
{{- $imgPrefix := strings.TrimSuffix "_MARK_" (relURL "_MARK_") -}}
{{- $content = replaceRE `(]*\ssrc=")/` (printf "${1}%s" $imgPrefix) $content -}}

{{- /* Render content. Trim trailing whitespace/newlines so a reuse used inline
       (e.g. `--version {{< reuse "..." >}} \`) doesn't drop a stray newline
       into the middle of a code-block continuation line. RenderString wraps
       single-line content in a paragraph and emits a trailing newline. */ -}}
{{- $rendered := $content | .Page.RenderString -}}
{{- $rendered = strings.TrimRight " \n\t" $rendered -}}
