{{- /* Shortcode: version Summary: Renders its body only on the versions the author names Group: gating CallForm: both Overrides: none Parameters: - version | string | no | — | Version string to import, for a self-closing call. - include-if | string | no | — | Render the body only on versions matching this token. - exclude-if | string | no | — | Render the body on every version EXCEPT those matching. Example: {{% version include-if="v2" %}} This paragraph appears only on v2 pages. {{% /version %}} Notes: `include-if` and `exclude-if` are read inside `utils/gate-decide.html`, the condition evaluator shared with `conditional-text`. They are documented here because a reader writing the call should not need to know that. The bulk of the template is condition resolution: derive the current version from the URL, match it against `params.versions`, and handle the `keepVersion` landing zone. There is one emit site, `utils/gate-emit.html`, which emits `.Inner` untouched. ### Interaction with rebase The rebase pipeline remaps OSS version tokens to their enterprise equivalents through each `params.versions` entry's `ossVersion`. A `keepVersion` block opts out of that remap. Getting the two confused is a known source of bugs: an enterprise token that collides with another entry's `ossVersion` is the shape that once broke kgateway's github-branch page. A `version` block inside a numbered list must wrap the WHOLE list item, including its `1.` marker. Wrapping only part of the item detaches the remainder from the list. */ -}} {{- $versions := .Site.Params.versions -}} {{- $condition := "" -}} {{- if $versions -}} {{- $version := .Page.FirstSection.RelPermalink -}} {{- $version_without_product := replace $version .Site.Params.folder "" -}} {{- $condition = trim $version_without_product "/" -}} {{- /* Path-segment fallback. The block above assumes URLs shaped like ///... (solo docs, test fixture). Consumers like kgw use /docs/
//... where FirstSection is /docs/ and `folder` isn't set, so $condition lands on "docs" and matches nothing. When the derived $condition contains no known linkVersion, walk the URL segments and pick the first one that matches a linkVersion. Only fires when the original logic missed, so it can't break the solo / fixture paths. */ -}} {{- $matched := false -}} {{- range $versions -}} {{- if and (ne .linkVersion "") (in $condition .linkVersion) -}} {{- $matched = true -}} {{- end -}} {{- end -}} {{- if not $matched -}} {{- $parts := split (trim .Page.RelPermalink "/") "/" -}} {{- range $p := $parts -}} {{- range $versions -}} {{- if and (not $matched) (eq .linkVersion $p) -}} {{- $condition = $p -}} {{- $matched = true -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- /* REMOVED: a second branch for sites that declared versions ONLY under site.Params.sections..versions. That shape is gone (CHANGELOG [0.2.2]) — a section-scoped version now tags itself inside the one site.Params.versions list — so `if $versions` above is reached by every versioned site, including the sections-only ones this branch existed for. It is worth recording what that branch got WRONG, because the tagged model makes the mistake unrepresentable rather than merely fixed: it flattened EVERY section's version list into one slice and matched the first hit, without scoping to the page's own section. On a site whose sections ship different version sets, a `standalone` page could gate against the `kubernetes` entry's canonical `.version` and silently render nothing. It stayed invisible only because agentgateway's two sections happened to ship identical version numbers, which sidebar.html's own comments note is not expected to last. */ -}} {{- end -}} {{- $currentProduct := .Site.Params.currentProduct | default "" -}} {{- $emitted := false -}} {{- /* NORMAL PATH: the page resolved to a version. Match include-if/exclude-if against BOTH the canonical version string (.version, e.g. "1.4.x") and the stable linkVersion token (.linkVersion, e.g. "main"/"latest"), so `include-if="main"` never needs a per-release bump. Mirrors the same matching in the Python doc-test extractor (_evaluate_version_block). */ -}} {{- if ne $condition "" -}} {{- range $versions -}} {{- if and (in $condition .linkVersion) (not $emitted) -}} {{- $productMatches := or (not $currentProduct) (eq .product $currentProduct) -}} {{- if $productMatches -}} {{- if partial "utils/gate-decide.html" (dict "sc" $ "tokens" (slice .version .linkVersion)) -}} {{- partial "utils/gate-emit.html" (dict "sc" $ "inner" $.Inner) -}} {{- $emitted = true -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- /* KEEPVERSION LANDING ZONE: no version resolved from the URL, but reuse.html injected a `version="…"` param naming the parent's version. Resolve that token to a canonical version (accepting .version, .linkVersion, or the OSS directory name) and gate on it. PRESERVED QUIRK, deliberately: an `exclude-if` block here emits nothing when `version=` does not resolve. In the old code that fell out of a substring test against an empty string; it is explicit now. There is no fixture for it, so it is kept as-is rather than "fixed" blind — changing it would silently start emitting content on every unresolvable enterprise-only page. */ -}} {{- if and (eq $condition "") (not $emitted) -}} {{- $versionImport := .Get "version" -}} {{- $versionAdjusted := "" -}} {{- range $versions -}} {{- if not $versionAdjusted -}} {{- if or (eq .version $versionImport) (eq .linkVersion $versionImport) -}} {{- $versionAdjusted = .version -}} {{- else if and .ossDir (eq .ossDir $versionImport) -}} {{- $versionAdjusted = .version -}} {{- end -}} {{- end -}} {{- end -}} {{- if $versionAdjusted -}} {{- range $versions -}} {{- if and (eq .version $versionAdjusted) (not $emitted) -}} {{- $productMatches := or (not $currentProduct) (eq .product $currentProduct) -}} {{- if $productMatches -}} {{- if partial "utils/gate-decide.html" (dict "sc" $ "tokens" (slice .version .linkVersion)) -}} {{- partial "utils/gate-emit.html" (dict "sc" $ "inner" $.Inner) -}} {{- $emitted = true -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}}
