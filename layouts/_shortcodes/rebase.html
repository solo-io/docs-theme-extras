{{- /* rebase: render content from another version's asset tree into the current page, with version-aware shortcode rewrites applied. Pipeline overview — each block below is one stage: 1. SETUP — resolve file path, page version, product, and look up the resource. Falls back to bare path if the versioned path isn't on disk. 2. CONTENT PREP — strip front matter; mark page for Mermaid / manual-cards detection. 3. FORM CONVERSION — bulk-rewrite percent-form shortcodes to angle- form so RenderString processes them, then revert specific shortcodes back to percent- form when their inner content must re-flow through markdown (tab, steps, include). 3b. SOURCE FILTERS — strip {{< upstream >}} blocks (OSS source-only content); unwrap {{< downstream >}} blocks (downstream-only content, hidden in source). 4. ARG INJECTION — pass the resolved version + product into shortcodes that need them (link-hextra, reuse). 5. VERSION REMAP — handle keepVersion= on the version shortcode, then two-pass OSS↔enterprise version-string swap via indexed placeholders. 5b. GATE FORM — normalize every TOP-LEVEL angle-form version / conditional-text gate to percent form, so gate-emit's raw .Inner re-enters markdown. Nested gates stay angle (percent pre-renders them). Runs AFTER 5 because the keepVersion guard is percent-only. Sentinel: GATE-FORM-NORMALIZATION-v1. 6. RENDER — hand the transformed markdown to RenderString. When adding a new shortcode that needs special treatment under rebase, find the right stage and add the rule there. The structural- HTML parity test in versioning.spec.ts (everything vs rebased) is the safety net — if you forget a stage, that test will fail. */ -}} {{/* ─── Stage 1: SETUP ──────────────────────────────────────────────── */}} {{ $file := .Get "file" }} {{/* Set to default value, here agentgateway. Run 'make server PRODUCT=' to assemble versioned assets." (.Get "file") .Page.RelPermalink }} {{ end }} {{/* For kgateway/envoy content, override product so link-hextra can apply envoy-specific path transformations (e.g. reference/api → /reference/api/kgateway).
