{{- /* Shortcode: rebase Summary: Renders a page from another version's asset tree, rewriting its shortcodes to match Group: reuse-versioning CallForm: both Overrides: none Parameters: - file | path | yes | — | Path to the source Markdown under assets/. Example: code-only Notes: The heaviest shortcode in the module. It takes a whole page authored against one version and renders it under another, rewriting the shortcodes inside so they resolve against the version the reader is actually on. The example is marked `code-only`: this cannot render without a real asset tree and a version context. ### Pipeline Each stage is a labelled block in the template. When adding a shortcode that needs special treatment under rebase, find the right stage and add the rule there. 1. **Setup** — resolve file path, page version and product, and look up the resource. Falls back to the bare path when the versioned path is not on disk. 2. **Content prep** — strip front matter; mark the page for Mermaid and manual-cards detection. 3. **Form conversion** — bulk-rewrite percent-form shortcodes to angle form so `RenderString` processes them, then revert specific shortcodes back to percent form where their inner content must re-flow through Markdown (`tab`, `steps`, `include`). `github-yaml` is on that revert list too. 4. **Source filters** — strip `upstream` blocks and unwrap `downstream` blocks, so a rebased page follows the same split as a native one. 5. **Argument injection** — pass the resolved version and product into the shortcodes that need them, `link-hextra` and `reuse`. 6. **Version remap** — handle `keepVersion` on the `version` shortcode, then do the two-pass OSS-to-enterprise version-string swap through indexed placeholders. 7. **Gate form** — normalize every TOP-LEVEL angle-form `version` and `conditional-text` gate to percent form, so `gate-emit`'s raw `.Inner` re-enters Markdown. Nested gates stay angle, because percent would pre-render them. Runs after the remap because the `keepVersion` guard is percent-only. 8. **Render** — hand the transformed Markdown to `RenderString`. The structural-HTML parity test in `versioning.spec.ts` compares the `everything` fixture page against its rebased twin. If you add a stage rule and forget one, that test is what catches it. */ -}} {{/* ─── Stage 1: SETUP ──────────────────────────────────────────────── */}} {{ $file := .Get "file" }} {{/* Set to default value, here agentgateway. This is required so that the product value will persist after the if statement. */}} {{ $product := "agentgateway" }} {{/* Resolve the content version from the page URL and prepend // to the file path so it resolves to the assembled directory (e.g. agw-docs/kubernetes/... → agentgateway/2.3.x/agw-docs/kubernetes/...). Scan every URL segment (not just index 1) so this works regardless of whether the baseURL has a path prefix (e.g. https://docs.solo.io/agentgateway/). The first segment that matches a known version wins. */}} {{ $version := "" }} {{ $urlParts := split .Page.RelPermalink "/" }} {{ range $urlPart := $urlParts }} {{ if not $version }} {{ range $.Site.Params.versions }} {{ if eq .version $urlPart }} {{ $version = .version }} {{ $product = .product | default "agentgateway" }} {{ end }} {{ end }} {{ end }} {{ end }} {{ $currentProduct := $.Site.Params.currentProduct | default "" }} {{ $doc := false }} {{ if and $version $currentProduct }} {{ $versionedFile := printf "%s/%s/%s" $currentProduct $version $file }} {{ $doc = resources.Get $versionedFile }} {{ if $doc }} {{ $file = $versionedFile }} {{ end }} {{ end }} {{ if not $doc }} {{ $doc = resources.Get $file }} {{ end }} {{/* Fail LOUDLY on a missing rebased resource: a wrong `file=` path or an incomplete assembly is real breakage we want to surface, not paper over with an empty section. `errorf` fails the build with a clear message. The `with $doc` guard sets $content only when the resource resolved, so a not-found $doc never falls through to `$doc.Content` on `false` — that would crash with a confusing "nil pointer evaluating resource.Resource.Content" instead of the actionable message below. So this is the same fail-the-build behavior, minus the misleading secondary error. */}} {{ $content := "" }} {{ with $doc }} {{ $content = .Content }} {{ else }} {{ errorf "rebase: resource not found: %q (page: %s). Run 'make server PRODUCT=' to assemble versioned assets." (.Get "file") .Page.RelPermalink }} {{ end }} {{/* For kgateway/envoy content, override product so link-hextra can apply envoy-specific path transformations (e.g. reference/api → /reference/api/kgateway). Version is NOT overridden — the URL-based inference above is correct. */}} {{ if in $file "kgateway/envoy" }} {{ $product = "envoy" }} {{ end }} {{/* ─── Stage 2: CONTENT PREP ───────────────────────────────────────── */}} {{/* Optional: mark that this page may contain Mermaid diagrams */}} {{ .Page.Store.Set "hasMermaid" true }} {{/* Suppress list.html's auto-generated section cards when the rebased content already provides its own {{< cards >}} block. Detected before shortcode conversion, so it catches both {{< cards >}} and {{% cards %}} forms. */}} {{ if or (in $content "{{< cards") (in $content "{{% cards") }} {{ .Page.Store.Set "hasManualCards" true }} {{ end }} {{/* Strip out front matter (--- ... ---) */}} {{ $clean := replaceRE `(?s)^---.*?---\s*` "" $content }} {{/* ─── Stage 3: FORM CONVERSION ────────────────────────────────────── */}} {{/* Convert percent-bracket shortcodes to angle-bracket so RenderString processes them. Tab/tabs are converted back below so their inner content gets markdown-rendered. */}} {{ $clean = replaceRE `\{\{%\s*` "{{< " $clean }} {{ $clean = replaceRE `\s*%\}\}` " >}}" $clean }} {{/* Convert inner tab back to percent-bracket so its code blocks get markdown-rendered. Leave outer tabs as angle-bracket so its block-level HTML is inserted after markdown parsing, not re-parsed. Re-parsing would let CommonMark treat the wrapping
as a type-6 HTML block and terminate any surrounding ordered/unordered list. */}} {{ $clean = replaceRE `\{\{<\s*(tab\s[^>]*)>}}` "{{% $1%}}" $clean }} {{ $clean = replaceRE `\{\{<\s*(/tab)\s*>}}` "{{% $1 %}}" $clean }} {{/* Convert steps back to percent-bracket. . */}} {{ $clean = replaceRE `\{\{<\s*(steps)\s*>}}` "{{% $1 %}}" $clean }} {{ $clean = replaceRE `\{\{<\s*(/steps)\s*>}}` "{{% $1 %}}" $clean }} {{/* Convert `include` back to percent-bracket. Hextra's include shortcode calls .RenderShortcodes on the target page and returns its raw markdown. With angle-bracket form, that markdown is inserted AFTER the outer markdown pass, so backticks, links, and headings appear as literal text. The percent form lets the outer markdown engine re-process the inserted content. Hextra explicitly documents include as a percent-form-only shortcode for this reason. */}} {{ $clean = replaceRE `\{\{<\s*(include\s[^>]*)>}}` "{{% $1%}}" $clean }} {{/* Convert `github-yaml` back to percent-bracket, for exactly the same reason as `include` above: it returns a markdown CODE FENCE, not HTML, so in angle-bracket form the ``` backticks are substituted after Goldmark has run and appear as literal text in prose. GENERAL RULE for anyone adding a shortcode to this module: if it emits raw MARKDOWN rather than HTML, it must be listed here, and its own doc comment must say it is percent-form-only. Stage 3's bulk %→< pass is unconditional, so a fence-emitting shortcode that is not restored here works fine on a normal page and silently breaks only under rebase. */}} {{ $clean = replaceRE `\{\{<\s*(github-yaml\s[^>]*)>}}` "{{% $1%}}" $clean }} {{/* ─── Stage 3b: SOURCE FILTERS ────────────────────────────────────── */}} {{/* Strip upstream blocks: content that should only appear in the OSS source repo and must not be included in the rebased downstream docs. */}} {{ $clean = replaceRE `(?s)\{\{<\s*upstream\s*>}}.*?\{\{<\s*/upstream\s*>}}` "" $clean }} {{/* Unwrap downstream blocks: content that is hidden in the OSS source repo but should appear when rebased into downstream docs. The wrapper tags are removed and the inner content is preserved. */}} {{ $clean = replaceRE `(?s)\{\{<\s*downstream\s*>}}(.*?)\{\{<\s*/downstream\s*>}}` "$1" $clean }} {{/* ─── Stage 4: ARG INJECTION ──────────────────────────────────────── */}} {{/* Adjust any relative doc links if needed */}} {{ $clean = replaceRE `\((\/?)docs\/` "(/" $clean }} {{/* Replace link and reuse shortcodes to pass version. `link` gets the same injection as link-hextra (which it now forwards to) so rebased content using either name resolves consistently — see link.html. The `link\s+` pattern requires whitespace right after "link" so it can't also match `link-hextra`. */}} {{ $clean = replaceRE `{{<\s*link-hextra\s*(.*?)>}}` (printf "{{< link-hextra $1 version=\"%s\" product=\"%s\" >}}" $version $product ) $clean }} {{ $clean = replaceRE `{{<\s*link\s+(.*?)>}}` (printf "{{< link $1 version=\"%s\" product=\"%s\" >}}" $version $product ) $clean }} {{ $clean = replaceRE `{{<\s*reuse\s*"([^"]+)"\s*>}}` (printf "{{< reuse \"%s\" \"%s\" \"%s\" >}}" "$1" $version $product ) $clean }} {{/* ─── Stage 5: VERSION REMAP ──────────────────────────────────────── */}} {{/* keepVersion: preserve version string, inject page version, convert to {{% %}} */}} {{ $clean = replaceRE `\{\{<\s*(version\s+(?:include|exclude)-if="[^"]+?")\s+keepVersion="true"\s*>}}` (printf `{{%% $1 version="%s" %%}}` $version) $clean }} {{/* Two-pass OSS→enterprise version remapping from [[params.versions]]. Pass 1 replaces OSS versions with indexed placeholders so overlapping version strings (e.g. OSS 2.2.x vs enterprise 2.2.x) never double-match. Pass 2 swaps placeholders for the enterprise versions. */}} {{ range $i, $v := $.Site.Params.versions }} {{- if and $v.ossVersion (ne $v.ossVersion $v.version) -}} {{- $oss := replaceRE `\.` `\.` $v.ossVersion -}} {{- $ph := printf "__V%d__" $i -}} {{- $clean = replaceRE (printf `(\{\{<\s*version\s[^>]*?(?:in|ex)clude-if="[^"]*?)%s` $oss) (printf "${1}%s" $ph) $clean -}} {{- end -}} {{ end }} {{ range $i, $v := $.Site.Params.versions }} {{- if and $v.ossVersion (ne $v.ossVersion $v.version) -}} {{- $ph := printf "__V%d__" $i -}} {{- $clean = replace $clean $ph $v.version -}} {{- end -}} {{ end }} {{/* Leave remaining {{< version >}} blocks in angle-bracket form so .Inner stays as raw markdown for version.html. The percent form ({{% %}}) would trigger Hugo's parent-context pre-render of .Inner BEFORE version.html runs, and indented inner content would get wrapped in 
 by
     CommonMark's "4 spaces = code" rule before we ever see it. */}}
