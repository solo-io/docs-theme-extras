{{- /* Shortcode: github-yaml Summary: Fetches a remote YAML file and renders it as a captioned code block Group: external-content CallForm: percent Overrides: none Parameters: - url | url | yes | — | The remote URL of the YAML file to fetch and display. Example: code-only Notes: **Percent form only.** This shortcode emits a Markdown code fence rather than HTML, so its output has to re-enter the Markdown renderer. Hugo inserts angle-bracket shortcode output verbatim without re-parsing it, so the angle form puts literal backticks on the page instead of a code block. Because of that it is also registered in `rebase.html`'s convert-back-to- percent-form list. Rebase's bulk percent-to-angle conversion would otherwise force it into the broken form on every rebased page. If you rename this shortcode, update that list too. The example is marked `code-only` because a live render would make a network request on every site build. ### Why this and not `github` inside a fence `github` can already inline a YAML file that the caller wraps in a fence, and for a one-off that is the simpler call. This shortcode exists for three things wrapping does not give you: 1. It strips the `yaml-language-server` schema directive from the first line. That line is an editor hint for the file's authors, is noise in published docs, and makes the rendered snippet differ from what a reader would paste. 2. It sets Hextra's `filename` and `base_url` codeblock attributes from the URL, so the block is captioned with the real file name and links back to its directory. See Hextra's `_markup/render-codeblock.html`. 3. It uses a date-stamped cache key, so a moving ref such as `refs/heads/main` refreshes at least daily instead of being pinned to whenever the getresource cache was last cold. `github` has no cache key, so Hugo's default keying applies. */ -}} {{- $url := .Get "url" -}} {{- /* Directory of the URL, for the caption's "view source" link. NOT `path.Dir`, which is a FILESYSTEM path function: it normalizes repeated separators, so `path.Dir "https://host/a/b.yaml"` returns `https:/host/a` — one slash after the scheme. That is what the original of this shortcode used, and every code block it rendered carried the malformed href (visible on agentgateway.dev; browsers mostly recover because the WHATWG URL parser tolerates extra-or-missing slashes on a special scheme, but a strict link checker does not have to). Trimming the last segment with a regex leaves the rest of the URL, including `://`, exactly as written. */ -}} {{- $dirURL := replaceRE `/[^/]*$` "" $url -}} {{- /* Date-stamped key so a moving ref refreshes at least once per day. */ -}} {{- $cacheKey := printf "%s-%s" $url (now.Format "2006-01-02") -}} {{- $attempt := try (resources.GetRemote $url (dict "key" $cacheKey "timeout" "15s")) -}} {{- with $attempt.Err -}} {{- warnf "github-yaml: failed to fetch %q: %s" $url . -}}

Error: Unable to load code from {{ $url }}

{{- else -}} {{- with $attempt.Value -}} ```yaml {base_url="{{ $dirURL }}",filename="{{ $url | path.Base }}"} {{ .Content | replaceRE "^# yaml-language-server.*\n" "" | safe.HTML }} ``` {{- else -}} {{- errorf "github-yaml: no content at %q (dead or moved URL) — fix or remove the reference" $url -}} {{- end -}} {{- end -}}
