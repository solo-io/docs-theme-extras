{{- /* Non-latest-version noindex — surgical (duplicates only). For versioned docs, an OLD version's copy of a page that STILL EXISTS in the current version is near-duplicate content competing for the same query, which splits ranking signal and often surfaces the old version. This marks those duplicates `noindex, follow` (follow so link equity still flows to the current version). Crucially, a page that exists ONLY in an old version — a feature that was removed in the current release — has NO current-version equivalent and is LEFT INDEXABLE, so it stays findable in search. That's the difference from a blanket per-version noindex: we suppress duplicates, not history. OPT-IN AND FAIL-SAFE. Activates only when the current version can be identified, by either of two signals (see the detection block below): an explicit `latest = true` flag, or a `linkVersion = "latest"` segment. [[params.versions]] version = "2.3.x" linkVersion = "latest" # auto-detected; no flag needed # latest = true # only needed when linkVersion isn't "latest" Detection is deliberately conservative rather than inferred from, say, a "(latest)"/"(current)" dropdown label — those are not uniform across repos (the docs hub even carries a stale "(latest)" label on an OLD entry), and guessing wrong would deindex live docs. A repo whose current version is a bare number and not served at /latest/ (e.g. docs hub) must use the explicit flag. Matching neither signal emits nothing — worst case is the pre-existing everything-indexable behavior. WHY noindex AND NOT canonical: Hextra's head.html has already emitted a self-referential `` before head-end.html runs, and the theme does not shadow head.html. Emitting a second, conflicting canonical makes search engines ignore BOTH; a second robots tag, by contrast, resolves deterministically to the most restrictive (noindex). So on a duplicate this emits an ADDITIONAL `` alongside Hextra's `index, follow`, and noindex wins. (A consumer wanting a single clean canonical-to-current tag can instead set `.Params.canonical` via a config cascade on its old version paths and leave `latest` unset here.) Existence lookup and version-segment extraction mirror _partials/navbar.html (folder/language-prefix aware). Called once per page from head-end.html. */ -}} {{- with site.Params.versions -}} {{- /* The current version's URL segment. Two detection paths, in order: 1. An explicit `latest = true` flag on the current version entry. This is the deliberate opt-in and works for ANY convention — a repo whose current version is a bare number (e.g. docs hub `linkVersion=2.3.x`) can only be marked this way. 2. Fallback: an entry whose `linkVersion` is literally "latest". kgw-oss and agw-oss serve the current version at /…/latest/, so the URL segment already encodes "current" and no extra field is needed. Repos matching neither (no flag, no "latest" segment) emit nothing — same fail-safe as before. */ -}} {{- $latestSeg := "" -}} {{- range . -}}{{ if eq (.latest | default false) true }}{{ $latestSeg = .linkVersion | default .version }}{{ end }}{{- end -}} {{- if not $latestSeg -}} {{- range . -}}{{ if eq (.linkVersion | default "") "latest" }}{{ $latestSeg = "latest" }}{{ end }}{{- end -}} {{- end -}} {{- if $latestSeg -}} {{- /* Find the version segment by SCANNING the URL for the first segment that matches a known version's linkVersion/version, rather than assuming a fixed position. Consumers differ in how many segments precede the version (dev: //…; docs hub: //…; kgw-oss: /docs/envoy//…) and not all set params.folder, so a positional skip is unreliable. Version strings ("2.2.x", "latest", "main") don't collide with real content or language segments in practice. */ -}} {{- $segments := split (trim $.RelPermalink "/") "/" -}} {{- $urlVersion := "" -}} {{- $versionIdx := -1 -}} {{- range $i, $seg := $segments -}} {{- if lt $versionIdx 0 -}} {{- range $.Site.Params.versions -}} {{- if or (eq (.linkVersion | default .version) $seg) (eq .version $seg) -}} {{- $urlVersion = $seg -}} {{- $versionIdx = $i -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- /* Only proceed for a KNOWN, NON-latest version segment. Pages with no version segment (landings) or already on the latest version are left alone. */ -}} {{- if and (ge $versionIdx 0) (ne $urlVersion $latestSeg) -}} {{- /* Rebuild this page's URL with the latest version swapped in, preserving any prefix segments before the version (e.g. /docs/envoy/). If that page exists, this old-version page is a duplicate → noindex it. A page that exists ONLY in the old version has no equivalent and is left indexable. */ -}} {{- $prefix := "" -}} {{- if gt $versionIdx 0 -}}{{ $prefix = delimit (first $versionIdx $segments) "/" }}{{- end -}} {{- $after := delimit (after (add $versionIdx 1) $segments) "/" -}} {{- $latestEquiv := "" -}} {{- if $prefix -}} {{- $latestEquiv = printf "/%s/%s/%s" $prefix $latestSeg $after -}} {{- else -}} {{- $latestEquiv = printf "/%s/%s" $latestSeg $after -}} {{- end -}} {{- $latestEquiv = strings.TrimRight "/" $latestEquiv -}} {{- if site.GetPage $latestEquiv -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}}
